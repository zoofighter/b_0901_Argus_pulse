## 구현 순서 (8일)

```
Day 1   .env + config.py + DB 연결 확인
Day 2   topic_generator.py  →  "오늘의 주제 3개" 터미널 출력
Day 3   blog_writer.py + thread_writer.py  →  파일 생성
Day 4~5 hourly_monitor.py  →  크론 자동 실행
Day 6   daily_digest.py  →  저녁 정리 보고서
Day 7~8 review_generator.py  →  뉴스 없는 날 과거 리뷰
```

---

## 만들 파일 목록

```
config.py              설정 중앙화 (경로, API 키, 임계치)
topic_generator.py     뉴스 + Thesis → 주제 추천 (P-01)
blog_writer.py         주제 → 2-Page 블로그 (P-02+P-03)
thread_writer.py       주제 → 구어체 스레드 (P-04)
hourly_monitor.py      매시간 뉴스 수집 + 스코어링
daily_digest.py        하루 뉴스 Thesis별 정리
review_generator.py    과거 블로그 예측 검증 (P-05)
notifier.py            디스코드/텔레그램 공통 알림
```

## 핵심 흐름도

```
[매일 08:00]
    ↓
고득점 뉴스 ≥ 2건?
  YES → 주제 추천 3~5개 표시
        🧑 사용자 선택 (10~30초)
        → 블로그 or 스레드 생성
        → 옵시디언 저장 + 디스코드
  NO  → 과거 블로그 자동 리뷰 생성

[매시간 09~21시]
    → 뉴스 수집 + Thesis 매칭
    → 80점+ 뉴스 즉시 알림

[매일 15:00, 21:00]
    → 데일리 다이제스트 생성·전송
```
