## 스레드 vs 블로그: 왜 개입 포인트가 다른가

스레드는 블로그보다 **개입 포인트가 다릅니다.** 블로그는 "주제 선택"이 핵심이었다면, 스레드는 특성상 다른 지점에서 사람 판단이 필요합니다.

```
블로그:  구조가 정해져 있음 (서론-본론-결론)
          → AI가 틀릴 여지가 적음
          → 주제만 고르면 됨

스레드:  흐름이 자유로움
          각 번호 한 줄 한 줄이 독립적
          구어체라 "말투/톤"이 글 전체를 좌우
          → AI가 "방향"을 잘못 잡으면 전체가 어색해짐
```

## 개입 포인트 3개

### ① 앵글(각도) 선택 — 가장 중요

같은 뉴스도 어떤 각도로 풀지가 스레드의 생명입니다:

```
[뉴스] SK온 ESS 1.5조 수주 + LG엔솔 리튬 10년 계약

─────────────────────────────────────────────
각도 A — "수혜 계산" 각도
  1. 한국 2차전지가 받는 미국 정책 수혜를 숫자로 계산해봤음
  2. 셀 만들면 kWh당 45달러 받음...
  → 팩트와 숫자 중심, 투자자 타깃

각도 B — "구조 변화" 각도
  1. 2차전지가 전기차에서 AI데이터센터로 넘어가는 중임
  2. 배터리가 이제 발전소 옆에 서 있음...
  → 산업 변화 스토리, 일반 독자 타깃

각도 C — "공장 가동률" 각도
  1. 공장은 다 지어놨는데 3분의 1만 돌리고 있음
  2. 채우려면 중국이 빠져야 함...
  → 리스크 중심, 회의적 시각
─────────────────────────────────────────────

🧑 어떤 각도로 쓸까요? (A/B/C):
```

### ② 도입부(1~5번) 확인 — 선택적

스레드는 첫 3줄이 클릭률을 결정합니다. AI가 도입부 초안을 먼저 보여주고 OK/수정을 받는 방식:

```
[Argus Pulse Bot]

📝 스레드 도입부 초안 (1~5번)

1. 2차전지가 전기차에서 AI데이터센터로 넘어가는 중임.
2. 이 와중에 미국이 중국 배터리에 세금 58%에 비상사태까지 때림.
3. 중국을 조질수록 한국이 반사이익이라 어제 2차전지가 다 올랐음.
4. 근데 이 수혜는 6년짜리임.
5. 중국을 제치려면 얼른 서둘러야 함;

──────────────────────
  OK — 이대로 전체 생성
  R  — 다시 써줘
  E  — 직접 수정하고 진행
```

### ③ 결말(마지막 5줄) 확인 — 거의 필수

스레드 결말은 "앞으로 볼 것" 또는 "핵심 한 줄"로 끝나야 합니다. 여기서 틀리면 전체 인상이 망가집니다:

```
[Argus Pulse Bot]

🔚 스레드 마무리 초안

151. 앞으로 볼 것 3개.
152. 10월 — 삼성SDI/SK온 LFP 양산 개시 여부
153. 올해 안 — 에너지부 세부 품목 확정
154. 3분기 실적 — 양극재 판가 반등 확인
155. 날짜가 다 정해져 있음.

──────────────────────
  OK — 발행
  R  — 결말 다시
  A  — 결말 추가/삭제
```

## 전체 흐름

```
[자동]                    [사람 10~60초]         [자동]
  ↓                            ↓                   ↓
뉴스 수집              ① 각도 선택 (필수)      전체 스레드 생성
Thesis 매칭                    ↓
각도 3개 생성          ② 도입부 OK? (선택)         ↓
                               ↓               ③ 결말 OK? (권장)
                                                    ↓
                                               옵시디언/트위터 발행
```

## 블로그 vs 스레드 개입 포인트 비교

| | 블로그 | 스레드 |
|---|---|---|
| **개입 1** | 주제 선택 | 각도 선택 |
| **개입 2** | (없음) | 도입부 확인 |
| **개입 3** | (없음) | 결말 확인 |
| **이유** | 구조가 정형화되어 AI가 잘 처리 | 흐름과 톤이 자유로워 방향 이탈 가능성 |
| **총 소요 시간** | 10~30초 | 30~90초 |

## 구현 방식

`blog_writer.py`에 `--format` 옵션 추가:

```python
FORMATS = {
    "blog":   "2-Page 마크다운 블로그 형식으로 작성해줘. 소제목 포함.",
    "thread": "1번부터 번호를 붙인 구어체 팩트 스레드로 작성해줘. "
              "각 줄은 1~2문장. '~임' '~함' 말투. 숫자와 팩트 중심.",
    "short":  "5줄 이내 핵심 요약으로 작성해줘.",
}

# 사용
$ python blog_writer.py --topic 1 --format thread
$ python blog_writer.py --topic 2 --format blog
```

## 핵심 인사이트

> **스레드에서 가장 중요한 개입은 "각도"입니다.**
>
> `askask.md`를 보면 — 같은 ESS 배터리 뉴스를 "수혜 계산" 각도로 풀었기 때문에
> 숫자가 자연스럽게 나열됐습니다. 만약 "산업 구조 변화" 각도였다면 완전히 다른
> 스레드가 됩니다.
>
> AI는 각도를 여러 개 생성하지만, "오늘 이 각도가 맞나"는 사람만 알 수 있습니다.
