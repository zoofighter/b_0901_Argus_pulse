# Argus Pulse — 과거 테마 추적기(Chronicle)와 Thesis(투자 가설) 연동 명세서

> **문서 번호**: SPEC-20260904-03  
> **작성 일자**: 2026-09-04  
> **관련 모듈**: `thesis_loader.py`, `thesis_checker.py`, `blog_writer.py`, `thread_writer.py`, `rag_engine.py`  
> **목적**: 과거 테마(HBM2/HBM3 등)의 내러티브 주기 데이터를 현재 활성 Thesis와 결합하여 역사적 유추(Historical Analogy) 기반의 심층 리서치 엔진 구축

## 1. 개요 및 연동 가치 (Overview & Value)

단순한 '최신 속보 요약'을 넘어, **"현재 우리가 겪고 있는 시장 논쟁과 85% 유사했던 과거의 선행 사이클"**을 자동으로 발굴하여 투자 가설(Thesis)에 연결합니다.

```
┌─────────────────────────────────────────────────────────────────────────┐
│              과거 테마 연대기 (Chronicle: HBM2/3, CXL, LFP 등)           │
└─────────────────────────────────────────────────────────────────────────┘
                                   │
                                   ▼ [유사 사이클 매핑 & 전례 추출]
┌─────────────────────────────────────────────────────────────────────────┐
│                  Thesis 투자 가설 (T-02 HBM4, T-07 CXL 등)               │
│  • frontmatter: precedent_cycle (선행 테마, 유사도, 사이클 단계)         │
│  • markdown body: ## 🏛️ 역사적 전례 비교 (Historical Analogy)          │
└─────────────────────────────────────────────────────────────────────────┘
                                   │
      ┌────────────────────────────┼────────────────────────────┐
      ▼                            ▼                            ▼
[1. 블로그/스레드 생성]       [2. Thesis 신뢰도 검증]      [3. 옵시디언 지식 그래프]
 "5년 전 HBM2E 수율 논쟁과     과거 변곡점 기준 대비        [[HBM2-HBM3-Chronicle]]
  동일한 패턴이 반복..."       현재 진척도 체크리스트 점검   <--> [[T-02 메모리 변화]]
```

## 2. Thesis Frontmatter 스키마 확장 (`precedent_cycle`)

각 `T-*.md` 파일의 YAML Frontmatter에 역사적 전례 메타데이터를 추가합니다.

```yaml
---
id: T-02
title: 메모리 산업의 변화
status: active
confidence: 75
priority: 5
rank: 2
# 🏛️ 과거 테마 추적기 연동 메타데이터
precedent_cycle:
  theme: "HBM2_to_HBM3_Supercycle"
  period: "2019~2023"
  current_phase: "Phase 2 (수율 검증 및 파트너십 확정기)" # 1:태동 -> 2:검증 -> 3:폭발 -> 4:성숙
  similarity: 0.85
  key_lesson: "초기 가격/수율 회의론 극복 후 엔비디아 독점 퀄 통과 시점에 P/E 리레이팅 발생"
  key_metrics:
    - "과거 변곡점: MR-MUF 수율 70% 돌파 시점 (2021)"
    - "현재 대응점: 베이스다이 4nm 수율 75% 및 TSMC/삼성 턴키 수주"
---
```

## 3. Thesis 마크다운 본문 `[역사적 전례 비교]` 섹션 템플릿

가설 문서 본문에 과거와 현재를 1:1로 대조하는 분석 테이블이 자동으로 유지됩니다.

```markdown
## 🏛️ 역사적 전례 비교 (Historical Analogy)
> 연계 테마 연대기: `[[HBM2-HBM3-Chronicle]]` (2019~2023)

| 비교 항목 | 과거 HBM2E/HBM3 국면 (2020~2022) | 현재 HBM4 커스텀 국면 (2026~) |
|---|---|---|
| **시장의 주된 회의론** | "단가 3배인데 누가 사나? 일반 D램으로 충분" | "커스텀 베이스다이 파운드리 비용 감당되나?" |
| **변곡점(Trigger)** | 엔비디아 A100/H100 표준 채택 발표 | 빅테크(구글 TPU, AWS Trainium) 전용 칩 수주 |
| **승자의 조건** | MR-MUF 수율 70% 선점 (SK하이닉스) | 베이스다이 파운드리 선단공정 확보 (TSMC/삼성) |
| **현재 진행 단계** | **2021년 상반기 (양산 직전 퀄 검증기)와 85% 유사** |
```

## 4. 콘텐츠 생성 엔진("역사의 거울") 자동 서술 연동

`blog_writer.py`와 `thread_writer.py`가 작동할 때, 관련 Thesis의 `precedent_cycle` 데이터를 프롬프트에 주입하여 **통찰력 넘치는 역사적 비교 문단**을 자동으로 생성합니다.

### ✍️ 실제 생성 예시 (블로그 도입부)
> *"2020년 HBM2E 도입 당시 시장은 30%대의 저조한 수율과 높은 단가를 이유로 회의론을 쏟아냈습니다. 하지만 승부는 2년 뒤 엔비디아 독점 공급으로 완전히 갈렸습니다. 지금 2026년 HBM4 커스텀을 둘러싼 '삼성 33% 점유율 착시' 논쟁 역시 정확히 5년 전과 동일한 내러티브 패턴을 밟고 있습니다."*

## 5. 지식 그래프 및 시스템 확장 로드맵

1. **Thesis 로더 확장 (`thesis_loader.py`)**:
   * `precedent_cycle` 파싱 및 과거 테마 연대기 파일과의 양방향 링크 관리
2. **과거 테마 아카이브 구축 (`historical_harvester.py`)**:
   * Hacker News / Reddit / 과거 증권사 PDF에서 연도별 테마 데이터 추출 및 `agent_vault/argus/Chronicles/` 저장
3. **가설 점검기 고도화 (`thesis_checker.py`)**:
   * 단순 뉴스 감시를 넘어, **"과거 사이클의 변곡점 체크리스트(수율 도달, 빅테크 채택 등)"**와 비교하여 가설 신뢰도(Confidence) 점수 보정
4. **옵시디언 MOC 연동**:
   * 옵시디언 그래프 뷰에서 `[[Chronicle]]` 노드와 `[[Thesis]]` 노드가 시각적으로 연결되어 테마 진화 계통도 형성
