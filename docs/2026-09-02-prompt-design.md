## P-01: 블로그 주제 추천 프롬프트

**역할**: 최신 뉴스 + Thesis를 결합하여 블로그 아이디어 3~5개 생성  
**입력**: 고득점 뉴스 목록, 활성 Thesis 목록  
**출력**: 제목 3종 + 관점 + 핵심 논점 + 2-Page 목차

```python
prompt = f"""당신은 테크/투자 전문 수석 콘텐츠 디렉터입니다.
아래의 [최신 핵심 뉴스]와 [나의 투자 테제]를 결합하여,
독자의 시선을 사로잡을 '2-Page 블로그 기획안' {num_topics}개를 생성하세요.

[최신 뉴스]
{news_text}

[투자 테제]
{thesis_text}

[작성 포맷]
각 주제마다:
1. 제목 (매력적이고 도발적인 헤드라인)
2. 주제 관점 (기술진화 / 기업격돌 / 공급망병목 / 팩트체크 중 택1)
3. 핵심 논점 (왜 지금 이 글을 읽어야 하는가?)
4. 2-Page 목차 (서론-본론1-본론2-결론)
"""
```

**4대 관점 프레임워크 (Angle)**:

| 관점 | 생성 공식 | 예시 제목 |
|---|---|---|
| **기술진화형** | [새 기술] + [패러다임 변화] | `공랭은 끝났다: 2026 데이터센터가 액체 냉각을 까는 이유` |
| **기업격돌형** | [1위 수성] vs [후발 추격] | `HBM4 전쟁: SK하이닉스 TSMC 동맹 vs 삼성 턴키 승부수` |
| **공급망병목형** | [표면 호재] + [진짜 병목] | `GPU는 넘치는데 전기가 없다: 빅테크가 원전으로 몰리는 이유` |
| **팩트체크형** | [대중의 환상] vs [현실] | `전고체 배터리 상용화의 착시: EV 대신 로봇으로 가는 이유` |

## P-02: 블로그 본문 생성 프롬프트

**역할**: 선택된 아웃라인으로 2-Page 블로그 초안 생성  
**입력**: 선택된 기획안, 해당 Thesis 가이드, 관련 뉴스  
**출력**: 마크다운 블로그 본문 (프론트매터 포함)

```python
prompt = f"""당신은 테크/투자 전문 블로그 작가입니다.
아래 [블로그 기획안]을 바탕으로 [블로그 양식]에 맞는 2-Page 초안을 작성하세요.

[블로그 기획안]
{selected_outline}

[Thesis 작성 가이드]
{thesis_guide}  # P-03에서 로드

[관련 뉴스 및 팩트]
{news_context}

[블로그 양식]
- 프론트매터: title, date, thesis, angle, status, tags, trigger_news
- 구조: 서론(훅) → 본론1 → 본론2 → 결론(인사이트+리스크+다음 주목점)
- 길이: 1,500~2,000자 (2-Page 기준)
- 필수 요소: 데이터 박스(핵심 수치), 면책 고지

[작성 시 자기 검토 후 제출]
작성 완료 후 스스로 확인:
✅ 필수 데이터 수치가 본문에 있는가?
✅ 최소 1개 비교 축을 사용했는가?
✅ 결론에 투자 관점이 있는가?
"""
```

> **참고**: Critic 에이전트 대신, 프롬프트 마지막에 **자기 검토** 지시를 포함하여 품질을 높임. 에이전트 구조 불필요.

## P-03: Thesis별 작성 가이드 (컨텍스트)

**역할**: 블로그 생성 시 Thesis별로 프롬프트에 추가하는 컨텍스트  
**구조**: 필수 데이터 + 비교 축 + 핵심 용어 + 핵심 질문

### T-01 데이터센터 컨텍스트
```
필수 데이터: 랙당 전력 밀도(kW), PUE, 글로벌 DC 전력소비(TWh)
비교 축: 공랭 vs 액체냉각 / 기존 그리드 vs 자체발전
핵심 용어: PUE, CDU, Direct-to-Chip, SMR, HVDC
핵심 질문: 이 뉴스가 DC 전력 병목을 악화시키나, 완화시키나?
```

### T-02 메모리 산업 컨텍스트
```
필수 데이터: HBM 대역폭(TB/s), 3사 점유율, HBM ASP 추이
비교 축: SK vs 삼성 vs 마이크론 / 범용 DRAM vs 커스텀 HBM
핵심 용어: HBM4, TSV, CoWoS, LTA, zHBM, NVHBM
핵심 질문: 3사 점유율 구도에 변화를 줄 이벤트인가?
```

### T-03 전고체 배터리 컨텍스트
```
필수 데이터: 에너지 밀도(Wh/kg), kWh당 비용, 파일럿 라인 현황
비교 축: 리튬이온 vs 전고체 / EV용 vs 하이엔드(로봇·군사)
핵심 용어: 고체 전해질, 황화물계, 덴드라이트, 바이폴라 적층
핵심 질문: 상용화 시점을 앞당기나, 뒤로 미루나?
```

### T-04 온디바이스 AI 컨텍스트
```
필수 데이터: NPU 성능(TOPS), 온디바이스 모델 크기, AI폰 출하량
비교 축: 클라우드 vs 온디바이스 / Apple vs 삼성 vs Google
핵심 용어: NPU, TOPS, Gemini Nano, 행동형 에이전트, Edge AI
핵심 질문: AI 처리를 클라우드에서 기기로 이동시키는 근거인가?
```

*(T-05~T-09는 `blog_thesis_guides.md` 참조)*

## P-04: 스레드 생성 프롬프트

**역할**: 구어체 팩트 나열형 콘텐츠 생성 (트위터/텔레그램용)  
**Human in the Loop**: 각도 선택(필수) → 도입부 확인(선택) → 결말 확인(권장)

```python
ANGLE_OPTIONS = {
    "A": "수혜 계산 각도 — 숫자와 팩트 중심, 투자자 타깃",
    "B": "구조 변화 각도 — 산업 변화 스토리, 일반 독자 타깃",
    "C": "공장/실행 각도 — 리스크 중심, 회의적 시각"
}

prompt = f"""당신은 투자/테크 분야의 트위터 인플루언서입니다.
아래 [뉴스와 팩트]를 [{selected_angle}]로 풀어,
구어체 번호 나열 스레드를 작성하세요.

[뉴스와 팩트]
{news_and_facts}

[Thesis]
{thesis_context}

[작성 규칙]
- 각 줄은 번호 + 1~2문장
- 말투: '~임' '~함' '~됨' (구어체)
- 숫자와 팩트를 구체적으로 (GWh, %, 조원 단위)
- 도입부(1~5번): 핵심 한 줄 요약으로 시작
- 결말(마지막 3~5번): '앞으로 볼 것' 또는 핵심 정리
- 전문 용어는 바로 뒤에 괄호로 설명
"""
```

## P-05: 과거 블로그 리뷰 프롬프트

**역할**: 오늘 새 블로그가 없는 날, 과거 글의 예측을 현재와 비교  
**입력**: 원본 블로그, 원본 작성 이후 최신 뉴스  
**출력**: 예측 정확도 평가 + 업데이트된 관점

```python
prompt = f"""당신은 투자 리서치 분석가입니다.
아래 [원본 블로그]의 주장을 [최신 뉴스]와 대조하여
예측 검증 리뷰를 작성하세요.

[원본 블로그] (작성: {original_date})
{original_content}

[그 이후 최신 뉴스]
{recent_news}

[작성 포맷]
## 📌 당시 핵심 주장
- 원본의 핵심 예측 2~3개 추출

## 🔄 그 이후 무슨 일이 있었나
- 관련 뉴스 기반으로 시간순 정리

## ✅ 예측 정확도 평가
- 각 예측별 맞음/틀림 + 이유
- Thesis {thesis_id} 신뢰도 변화: {old_confidence} → {new_confidence}점

## 💡 업데이트된 관점
- 이 경험에서 배울 점
- 향후 같은 패턴에서 적용할 인사이트
"""
```
