## 1. 개요 및 기획 배경 (Background)

### 1) 핵심 질문
* **Q1. 과거 트위터(X)에서 HBM2, HBM3가 태동하고 확산되던 시점의 시장 반응을 찾을 수 있는가?**
* **Q2. 이를 바탕으로 "지나간 과거 테마 추적기(Historical Theme Tracker)"를 구축할 수 있는가?**

### 2) 과거 테마 추적기의 가치 (Why It Matters)
* **내러티브 사이클의 패턴 발견**: 신기술(HBM2 $\rightarrow$ HBM3 $\rightarrow$ HBM4, CXL, LPU 등)이 등장할 때 시장이 겪는 **[초기 회의론 $\rightarrow$ 수율/양산 논쟁 $\rightarrow$ 빅테크 채택 $\rightarrow$ 밸류에이션 리레이팅]**의 전형적인 타임라인과 심리 변곡점을 파악.
* **역사의 유추(Historical Analogy)**: 현재 우리가 겪고 있는 `HBM4 커스텀 논쟁`, `CXL 시장 개화`, `유리기판 상용화` 이슈를 과거 `HBM2E 수율 논쟁`이나 `HBM3 엔비디아 독점기`와 비교하여 투자 통찰 도출.

## 2. 데이터 수집 가능성 및 채널 분석 (Feasibility)

```
[데이터 채널별 과거 추적 가능성]

1. X (트위터)         : 🟡 조건부 가능 (비용/스크래핑 제약 있으나 타겟팅 수집 가능)
2. Reddit / HackerNews: 🟢 100% 무료/완전 개방 (API로 2015~2023년 전수 수집)
3. 증권사 과거 리포트 : 🟢 100% 무료/확보 가능 (한경컨센서스 등 2018~2023 PDF)
4. 반도체 전문 매체    : 🟢 아카이브 수집 가능 (SemiAnalysis, AnandTech, 디일렉 등)
```

### 1) 트위터(X) 과거 데이터 수집 방안
| 구분 | 공식 X API (Full Archive) | 비공식 스크래퍼 (Twikit / Playwright) |
|---|---|---|
| **조회 범위** | 2006년 이후 전 트윗 | 2018~2023년 특정 키워드/기간 검색 |
| **비용** | 월 $5,000 (Pro 티어 필수, 고비용) | **무료 (계정 세션 쿠키 기반)** |
| **검색 쿼리** | `(HBM2 OR HBM3 OR "SK hynix") since:2020-01-01 until:2022-12-31` | 동일 고급 검색 쿼리 사용 |
| **품질/필터** | `min_faves:50`, `lang:en/ko` | 좋아요/리트윗 상위 영향력 트윗 위주 추출 |
| **평가** | 개인/연구용으로는 비현실적 | **헤드리스 브라우저/Twikit으로 타겟 수집 적합** |

### 2) 보조/강력 대체 채널 (신뢰도 높은 테크 커뮤니티)
* **Hacker News (Algolia API)**:完全 무료 오픈 API (`hn.algolia.com/api/v1/search_by_date?query=HBM2&numericFilters=created_at_i<1672531199`)로 2015~2022년 테크 전문가들의 토론 전수 수집 가능.
* **Reddit Pushshift API**: `r/hardware`, `r/stocks`, `r/AMD_Stock` 등에서 과거 HBM2/3 도입 당시의 생생한 토론 수집.
* **과거 증권사 리포트 (2019~2023)**: 당시 애널리스트들의 목표주가, CAPEX 추정치, 공급과잉/부족 논쟁 수집.

## 4. HBM2 $\rightarrow$ HBM3 추적 케이스 스터디 (예시 시나리오)

추적기를 가동했을 때 복원되는 내러티브 타임라인 예시:

| 시기 | 기술 단계 | 시장 내러티브 (트위터/커뮤니티) | 주요 사건 및 팩트 |
|---|---|---|---|
| **2018~2019** | HBM2 | *"비싸고 발열 심해서 GPU 일부에만 쓰이는 틈새 규격"* (회의론) | AMD Vega 탑재 후 고비용 논란 |
| **2020~2021** | HBM2E | *"수율 50%도 안 나온다? 삼성이 포기할까?"* (생존 경쟁) | SK하이닉스 HBM2E 개발 성공, 엔비디아 A100 탑재 발표 |
| **2022.상반기**| HBM3 태동 | *"챗GPT 직전: 데이터센터 필수재인가 사치재인가?"* | SK하이닉스 세계 최초 HBM3 양산 |
| **2023.초~중** | HBM3 폭발 | *"독점 공급과 P/E 30배 리레이팅의 시작"* | 엔비디아 H100 숏티지, 하이닉스 주가 100% 랠리 |

> 💡 **현재 시사점 연계**: *"과거 2020년 HBM2E 수율 회의론 당시 삼성이 겪었던 시행착오가 현재 2026년 HBM4 커스텀 파운드리 진입기에서 어떻게 반복/역전되고 있는가?"*를 분석 가능.

## 5. 단계별 구현 계획 (Roadmap)

### 📌 1단계: 과거 데이터 수집 도구 구축 (`historical_harvester.py`)
* **목표**: 2019~2023년 HBM2, HBM3, CXL 관련 데이터셋 확보
* **구현 세부**:
  1. `hn_harvester.py`: Hacker News Algolia API로 2018~2023년 "HBM", "HBM2", "HBM3" 토론 추출
  2. `twitter_archive_scraper.py`: Playwright / Twikit 기반으로 연도별 상위 반응 트윗(Top Liked Tweets) 100건 선별 추출
  3. `99.raw/history/` 디렉터리에 연도별 JSON/MD로 저장

### 📌 2단계: 타임라인 & 내러티브 복원 엔진 (`narrative_tracer.py`)
* **목표**: 수집된 과거 원시 데이터를 LLM으로 정제하여 "테마 연대기" 생성
* **구현 세부**:
  * 4단계(배경 $\rightarrow$ 촉발 $\rightarrow$ 과열 $\rightarrow$ 성숙) 내러티브 구조화
  * 핵심 참여자(엔비디아, SK하이닉스, 삼성, 마이크론)별 당시 포지션 복원

### 📌 3단계: 과거 vs 현재 유추(Analogy) 분석기 (`analogy_engine.py`)
* **목표**: 현재 진행 중인 가설(T-02 HBM4, T-07 CXL, T-11 유리기판)과 과거 테마를 1:1 비교
* **구현 세부**:
  * 프롬프트: `"현재 T-02(HBM4 커스텀) 논쟁과 2020년 HBM2E/HBM3 초기 국면의 공통점과 차이점을 표로 분석하라"`
  * 블로그/스레드 생성기(`blog_writer.py`, `thread_writer.py`)에 `--history` 옵션으로 과거 유추 컨텍스트 주입

### 📌 4단계: RAG 및 옵시디언 지식 베이스 영구 편입
* `rag_engine.py`에 `argus_history` 컬렉션 추가
* `agent_vault/argus/Chronicles/` 폴더로 과거 테마 연대기 마크다운 자동 동기화
