# AI 블로그 주제 자동 생성기 (Topic Generator) 설계서

> **작성일**: 2026-09-02  
> **목적**: 수집된 뉴스, 산업 PDF 지식, 사용자 가설(Thesis)을 교차 분석하여 매력적인 2-Page 블로그 주제와 아웃라인을 자동 생성

## 1. 블로그 주제 생성기의 핵심 아이디어

단순히 "오늘의 뉴스 요약"을 주제로 잡는 것이 아니라, **3가지 축의 교집합**에서 폭발력 있는 주제를 도출합니다.

```
 [ 최신 고득점 뉴스 ] ──────┐
 (예: TSMC 2nm 수율 이슈)    │
                            ├─▶  🧠 [LLM 주제 생성기] ─▶  📝 4가지 관점의 블로그 주제 추천
 [ 나의 투자 가설(Thesis) ]  │   (Topic Ideation Engine)     + 2-Page 구조(목차/핵심 논점)
 (예: 파운드리 경쟁 구도)     │
                            │
 [ 산업 PDF/위키 배경지식 ]  ─┘
 (예: GAA 트랜지스터 구조)
```

---

## 2. 블로그 주제를 발굴하는 4대 프레임워크 (Angle)

주제 생성기는 매번 똑같은 포맷이 아니라, 다음과 같은 **4가지 시각**으로 주제를 제안합니다:

| 관점 (Angle) | 생성 공식 | 블로그 제목 예시 |
|---|---|---|
| **① 기술 진화형 (Tech Deep-dive)** | [새 기술/규격] + [산업 패러다임 변화] | *"공랭은 끝났다: 2026 데이터센터가 액체 냉각 배관을 먼저 까는 이유"* |
| **② 기업 격돌형 (Versus Battle)** | [1위 기업 수성] vs [후발주자 추격] | *"HBM4 전쟁: SK하이닉스의 TSMC 동맹 vs 삼성전자의 턴키 승부수"* |
| **③ 병목/공급망형 (Bottleneck)** | [표면적 호재] 뒤에 숨은 [진짜 병목] | *"GPU는 넘치는데 전기가 없다: 빅테크가 원전과 SMR로 몰려가는 까닭"* |
| **④ 역발상/팩트체크 (Reality Check)** | [대중의 환상/착시] vs [실제 상용화 시점] | *"전고체 배터리 상용화의 착시: 3천만 원대 EV 대신 로봇으로 가는 이유"* |

## 3. 주제 생성 결과 예시 (Output Schema)

주제 생성기를 실행하면 다음과 같이 **즉시 글을 쓸 수 있는 기획안 카드** 형태로 출력됩니다:

```markdown
### 📌 [추천 주제 1] "데이터센터 전력난과 2026 SMR(소형원전) 테마의 실체"
* **분류**: 병목/공급망형 | **관련 테제**: ① 데이터센터의 변화
* **배경 뉴스/트리거**: 빅테크의 전력 PPA 계약 급증 및 그리드 인허가 지연 뉴스 (점수: 85점)
* **핵심 타깃 독자**: AI 인프라 및 에너지 전환 투자자
* **2-Page 추천 목차**:
  1. 랙당 100kW 시대, 왜 변전소와 전력망이 최대 병목인가?
  2. 빅테크(MS·구글·아마존)의 에너지 전략: 태양광에서 원전·SMR로
  3. 실질 수혜주 체크: 발전 사업자 vs 고압 변압기/냉각 인프라 기업
* **추천 썸네일 키워드**: "AI 데이터센터, 전력 절벽을 만나다"
```

        SELECT company, title, score, snippet FROM news
