## 1. 프로젝트 개요

### 1.1 프로젝트명
**Argus Pulse** — LangGraph 멀티에이전트 기반 시장 인텔리전스 엔진

### 1.2 목적
사용자의 투자 가설(Thesis)과 관심 산업에 대해, 다양한 소스(산업 PDF · 웹 자료 · 실시간 뉴스)를 통합 분석하여 **자동화된 인사이트 보고서**를 주기적으로 생성하는 시스템.

### 1.3 핵심 가치
- 수동으로 흩어진 자료를 읽는 시간 절약
- 가설 기반 투자 판단을 체계적으로 추적
- 시간이 갈수록 축적된 지식으로 분석 품질 향상 (RAG 순환)

## 3. 기능 요건 (Functional Requirements)

### FR-01: 데이터 인제스트

| 항목 | 상세 |
|---|---|
| **설명** | 다양한 형식의 자료를 텍스트로 변환하고 벡터 DB에 저장 |
| **입력 소스** | ① 산업 PDF (20~30장+) ② 웹 자료 (.md, .txt, .html, 200장+) ③ 한국경제 기사 |
| **처리** | 텍스트 추출 → 청킹 (1000자, 200자 overlap) → 임베딩 → ChromaDB 저장 |
| **중복 방지** | 파일 해시(SHA256) 기반으로 이미 인제스트된 파일 스킵 |
| **증분 지원** | 새 파일 추가 시 기존 데이터에 영향 없이 추가 인제스트 |
| **추적 원문** | R-01, R-02, R-12 |

### FR-02: 실시간 뉴스 수집

| 항목 | 상세 |
|---|---|
| **설명** | 기존 `b_0826_news_research` 뉴스 수집기를 연동하여 실시간 뉴스 수집 |
| **소스** | Naver News API, Google News RSS, DuckDuckGo, Yahoo Finance RSS |
| **처리** | 수집 → 4축 스코어링 → SQLite 저장 |
| **대상 종목** | companies.csv 기준 15개 종목 (국내 4개 + 해외 11개) |
| **추적 원문** | R-08 |

### FR-03: RAG 검색 엔진

| 항목 | 상세 |
|---|---|
| **설명** | 벡터 DB + 뉴스 DB를 결합한 하이브리드 검색 |
| **컬렉션** | ① `argus_knowledge` (기초 지식: PDF, 웹 자료) ② `argus_reports` (축적 지식: 생성된 리포트) |
| **검색 방식** | 두 컬렉션 동시 검색 + SQLite 최신 고득점 뉴스 결합 |
| **순환 구조** | 에이전트 산출물이 `argus_reports`에 재인제스트 → 시간이 갈수록 컨텍스트 풍부해짐 |
| **추적 원문** | R-04, R-05, R-10, R-14 |

## 4. 비기능 요건 (Non-Functional Requirements)

### NFR-01: 실행 환경
- **로컬**: macOS (Python 3.13, Anaconda)
- **원격**: Oracle Cloud VM (향후 배포 대응)

### NFR-02: 기술 스택 제약
| 항목 | 기술 | 비고 |
|---|---|---|
| 멀티에이전트 프레임워크 | LangGraph 1.0.6 | 이미 설치됨 |
| LLM | Gemini 2.5 Flash | 비용 효율, 기존 키 보유 |
| 벡터 DB | ChromaDB 1.5.5 | 이미 설치됨, 로컬 |
| 뉴스 DB | SQLite | b_0826 기존 구조 유지 |
| PDF 파싱 | pypdf 6.10.0 | 이미 설치됨 |
| 텍스트 청킹 | langchain-text-splitters | 이미 설치됨 |

### NFR-03: 기존 자산 의존성
- `b_0826_news_research` 프로젝트를 `sys.path`로 참조
- 해당 프로젝트의 `.env` (API 키), `collector.py`, `scorer.py`, `notifier.py`, `db/database.py` 활용

### NFR-04: 성능
- 심층 보고서 1회 생성: 목표 **60초 이내**
- 뉴스 수집 1회: 기존 **10~30초** 수준 유지

### NFR-05: 데이터 보존
- 로컬 아카이브: 무기한 보존
- 뉴스 DB: 30일 초과 자동 정리 (기존 로직)
- ChromaDB: 영구 보존 (인제스트된 지식 + 생성 리포트)
