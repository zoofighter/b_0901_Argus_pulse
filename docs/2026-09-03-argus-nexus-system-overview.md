# 🦅 Argus Nexus (아르고스 넥서스)
## AI 투자 테제 검증 & 멀티채널 리서치 인텔리전스 시스템

> **문서 작성일**: 2026-09-03  
> **시스템 정식 명칭**: **Argus Nexus (아르고스 넥서스)** *(구 프로젝트 코드명: Argus Pulse)*  
> **시스템 정의**: 42개 증권사 리서치 리포트(PDF)와 실시간 뉴스를 결합하여, 투자 가설(Thesis)을 스스로 검증하고 고품질 텍스트(블로그·스레드·다이제스트·리뷰)를 자율 생산하는 **지능형 지식 순환 리서치 에이전트**

---

## 1. 시스템 네이밍 배경 및 비전

### 왜 'Argus Nexus'인가?
- **Argus (100개의 눈)**: 그리스 신화 속 100개의 눈으로 세상을 끊임없이 감시하는 거인. 24시간 잠들지 않고 전 세계 테크 뉴스, 공시, 증권사 리포트의 미세한 변화를 추적합니다.
- **Nexus (연결점 & 중심핵)**: 단순 뉴스 스크랩에 머물지 않고, **[실시간 뉴스] ⟷ [증권사 심층 리포트] ⟷ [나의 투자 가설(Thesis)] ⟷ [멀티채널 콘텐츠 발행]**의 모든 지식과 통찰이 교차하고 순환하는 지능형 허브를 의미합니다.

## 3. 핵심 기능 6가지 요약

### ① 지식 RAG 엔진 & 순환 루프 (Knowledge RAG & Ingestion)
- **42개 증권사 리포트 인제스트**: PDF 원문에서 텍스트와 핵심 수치를 파싱하여 ChromaDB 영속 벡터 DB에 저장 (`argus_knowledge`).
- **자체 산출물 재학습**: 시스템이 발행한 블로그/다이제스트를 다시 벡터 DB에 적재(`argus_reports`)하여, 다음 글 작성 시 과거 자신의 논리를 기억하고 인용하는 영구적 지식 순환 달성.
- **`--rag` 선택 토글**: 신속한 작성이 필요할 때는 일반 모드(5~10초), 증권사 추정치 인용이 필요할 때는 심층 RAG 모드를 자유롭게 선택 가능.

### ② 투자 가설 자동 점검기 (Autonomous Thesis Checker)
- 사용자가 설정한 38개 투자 가설(`thesis/T-XX.md`)을 시스템이 상시 추적.
- 최신 7일 뉴스 및 증권사 리포트 팩트를 대조하여 가설의 **신뢰도(Confidence, ±15%)를 자동 재평가**.
- 마크다운 파일 내 `## 지지 근거`, `## 반박 근거` 섹션에 날짜별 팩트 히스토리를 사람의 개입 없이 스스로 누적 기록.

### ③ 시니어 톤 & 고품질 콘텐츠 생성기 (Writer Engine)
- **블로그 (`blog_writer.py`)**: 불필요한 기초 금융 용어(CAPEX, ROIC 등)의 괄호 설명을 배제하고, 첫 문장 볼드 강조 및 3~4열 마크다운 비교 표(Table)를 필수로 배치하여 전문 애널리스트 수준의 가독성 구현.
- **스레드 (`thread_writer.py`)**: 3대 각도(A: 수혜/숫자, B: 산업스토리, C: 회의론/리스크) 지원 및 모바일 완독형(`compact`, 10~15줄) 옵션 제공.

### ④ AI 자가 품질 검수위원 (Critic Agent)
- 초안 작성 즉시 최고 검수위원(Editor-in-Chief) 프롬프트가 가동되어 **5대 기준 100점 만점으로 자체 채점**:
  1. 수치 및 팩트 밀도 (25점)
  2. 인용 및 근거 충실도 (25점)
  3. 비교 표 및 시각 구조 (20점)
  4. 톤앤매너 및 전문성 (15점)
  5. 결론 및 인사이트 (15점)
- **80점 미만 시 지적 사항을 바탕으로 1회 자동 수정(Refine) 루프**를 실행한 후 최종 발행.

### ⑤ 듀얼 LLM 무중단 페일오버 (Dual LLM Zero-Downtime)
- 메인 모델(`gemini-3.7-flash`)이 과부하(503)나 할당량 초과 시, 로컬 오픈소스 엔진인 **`opencode/muse-spark-1.2-contributor-free`로 0초 만에 자동 전환**되어 어떤 상황에서도 파이프라인이 멈추지 않음.

### ⑥ 옵시디언 전용 폴더 체계 & 백그라운드 자동화
- **완전 격리 볼트 구조**: 모든 결과물이 옵시디언 볼트의 **`agent_vault/argus/`** 디렉터리 하위(`Blog/`, `Thread/`, `Digest/`, `Review/`, `Theses/`)로만 깔끔하게 분류 동기화.
- **24시간 자동화 스케줄**: 시스템 백그라운드(`crontab`)에 상시 등록되어 매일 08:00 아침 추천, 09~21시 매시간 뉴스 감시, 21:00 RAG 다이제스트, 21:05 Thesis 점검을 자율 수행하고 결과를 디스코드(Discord)로 브리핑.

## 4. 운영 명령어 퀵 레퍼런스

```bash
# 1. 원클릭 통합 제어 센터 실행 (추천)
./run.sh
# 또는 python argus.py

# 2. RAG 심층 모드 블로그 작성 (Critic 자가검수 포함)
python blog_writer.py --topic '...' --rag --critic

# 3. 모바일 완독형 스레드 작성
python thread_writer.py --topic '...' --angle A --length compact --rag

# 4. 과거 예측 사후 검증 리포트 발행
python review_generator.py --rag

# 5. 투자 가설(Thesis) 전체 신뢰도 자동 점검
python thesis_checker.py

# 6. 옵시디언 agent_vault/argus/ 수동 일괄 동기화
python obsidian_sync.py

# 7. 디스코드 웹훅 상태 점검
python notifier.py --test
```
