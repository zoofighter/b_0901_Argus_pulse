# Argus System — 수기 뉴스 및 인사이트 기록 가이드 (Manual News Logging Guide)

> **문서 번호**: GUIDE-20260906-01  
> **작성 일자**: 2026-09-06  
> **목적**: 자동 크롤러가 수집하지 못한 고가치 유료 리포트, 텔레그램 속보, 오프라인 세미나 인사이트를 수기로 테제 및 지식망에 반영하는 방법 명세

---

## 1. 개요 및 3가지 수기 입력 방식

자동 수집기가 놓친 뉴스나 비공개 정보(유료 리포트, 전문가 대화, 컨퍼런스 내용 등)는 다음 **3가지 방법** 중 가장 편한 방식으로 기록할 수 있습니다:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       수기 뉴스/인사이트 기록 3대 방식                        │
├───────────────────────┬────────────────────────────┬────────────────────────┤
│  방법 1. 옵시디언 직접 기입│  방법 2. 퀵 메모 노트 생성  │  방법 3. 원클릭 CLI 도구│
├───────────────────────┼────────────────────────────┼────────────────────────┤
│  • 테제 MD 본문 '지지/  │  • 'Inputs/' 폴더에 간이   │  • 'python3 manual_    │
│    반박 근거'에 직접 추가│    마크다운 메모 작성      │    news_injector.py'   │
│  • 가장 빠르고 직관적임 │  • 긴 분석/캡처 이미지 첨부│  • DB/랭킹/볼트 일괄 반영│
└───────────────────────┴────────────────────────────┴────────────────────────┘
```

---

## 2. [방법 1] 옵시디언 테제 본문에 직접 추가 (가장 간편한 방법)

옵시디언에서 해당 테제 파일(예: `T1-01 메모리 산업의 변화.md`)을 열고 본문 하단의 **`## 지지 근거`** 또는 **`## 반박 근거`** 섹션에 날짜와 함께 추가합니다.

### 작성 예시:
```markdown
## 지지 근거 (Supporting Evidence)
- 2026-09-06: [수기:디일렉] SK하이닉스, 16단 HBM4용 하이브리드 본딩 파일럿 장비 발주 완료 확인.
- 2026-09-07: [수기:세미콘 컨퍼런스] 엔비디아 담당 임원 "루빈 아키텍처에서 TSMC 파운드리 베이스다이 채택 확정" 발언.

## 반박 근거 (Counter / Risk Evidence)
- 2026-09-08: [수기:모건스탠리] 2027년 HBM CAPEX 공급과잉 우려 리포트 발간 (신뢰도 -5p 요인).
```

---

## 3. [방법 2] 옵시디언 퀵 메모 노트 작성 (별도 메모 형태)

긴 기사 전문이나 이미지 캡처, 개인 분석을 따로 독립된 노트로 보관하고 싶을 때 사용합니다.  
`agent_vault/argus/Inputs/` 폴더에 마크다운 파일을 생성합니다:

### `Inputs/2026-09-06-TSMC-2나노-웨이퍼-단가-급등.md` 예시:
```markdown
---
type: manual-news
date: 2026-09-06
source: "대만 공상시보 유료판"
title: "TSMC 2나노 웨이퍼 단가 3만 달러 돌파 및 애플 전량 선점"
thesis:
  - "[[T1-08-파운드리-2nm-공정과-GAA-격돌|T1-08]]"
  - "[[T1-01-메모리-산업의-변화|T1-01]]"
companies:
  - "[[Company-TSMC|TSMC]]"
  - "[[Company-Apple|Apple]]"
score: 88
nature: supporting  # supporting(지지) | counter(반박) | neutral(중립)
---

# 📌 TSMC 2나노 웨이퍼 단가 3만 달러 돌파

### 1. 핵심 팩트
- 2nm GAA 공정 웨이퍼당 가격이 3만 달러를 돌파하며 3nm 대비 50% 급등.
- 2026년 하반기 초기 CAPA의 80% 이상을 애플이 독점 예약.

### 2. 가설 영향 및 나의 생각
- [[T1-08]] 파운드리 2nm 공정 가설: 애플의 선점으로 엔비디아/AMD의 2nm 도입이 2027년으로 지연될 가능성 ➔ 관련 테제 신뢰도 강화.
```

* **효과**: Dataview에 의해 `T1-08` 테제 상세 페이지와 Master MOC에 자동 링크되어 집계됩니다.

## 4. [방법 3] 파이썬 원클릭 CLI 주입기 (`manual_news_injector.py`)

터미널에서 명령어 한 줄 또는 대화형 마법사로 DB 적재, 테제 MD 갱신, 모멘텀 재계산, 옵시디언 동기화를 한 번에 끝내는 방법입니다.

### ① 대화형 마법사 모드 (Interactive Wizard)
```bash
python3 manual_news_injector.py
```
* 터미널 질문에 따라 제목, 테제 ID(`T1-01`), 지지/반박 여부, 점수를 입력하면 자동으로 전 시스템에 반영됩니다.

### ② 한 줄 커맨드라인 모드
```bash
python3 manual_news_injector.py \
  --title "TSMC 2나노 웨이퍼 3만불 돌파 및 애플 독점 예약" \
  --thesis T1-08 \
  --score 85 \
  --source "대만공상시보" \
  --nature supporting \
  --delta 5
```
* `--delta 5`: 해당 테제의 신뢰도 점수를 즉시 +5%p 상향 조정합니다.

## 5. 요약 및 권장 가이드

* **간단한 1줄 뉴스/메모**: **`방법 1`** (옵시디언 해당 테제 파일의 `## 지지 근거`에 바로 적기)
* **터미널 작업 중이거나 모멘텀 점수까지 즉시 반영하고 싶을 때**: **`방법 3`** (`python3 manual_news_injector.py`)
* **긴 스크랩이나 PDF/이미지 첨부가 필요할 때**: **`방법 2`** (독립 메모 노트 작성)
