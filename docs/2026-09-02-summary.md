## 핵심 설계 내용 요약

### ① 자료 입력 — 세 가지 소스

| 소스 | 설명 | 양 |
|---|---|---|
| 📄 산업 PDF | 반도체, 배터리 등 산업 분석 자료 | 20~30장 |
| 🌐 웹 자료 | 한국경제 등 관심 기사 (2025년~) | 200장+ |
| 📰 실시간 뉴스 | 기존 뉴스 검색기(`b_0826`)가 자동 수집 | 매번 50건+ |

### ② AI 분석 — LangGraph 멀티에이전트

6명의 AI 에이전트가 팀으로 일함:

```
🎯 팀장(Orchestrator) — "이번에 심층 보고서를 만들자"
  ↓
🔍 조사원(Researcher) — PDF/웹/뉴스에서 관련 자료 검색
  ↓
📊 분석가(Analyst) — 검색된 자료에서 패턴과 의미 도출
  ↓
🔬 가설검증(Thesis Checker) — 내 투자 가설이 맞는지 확인
  ↓
✍️ 작성자(Report Writer) — 보고서 초안 작성
  ↓
🧐 품질관리(Critic) — "이 보고서 괜찮나?" → 부족하면 다시 쓰게 함
```

### ③ 산출물 — 보고서 4종

| 보고서 | 주기 | 쉬운 설명 |
|---|---|---|
| 📊 심층 보고서 | 1시간마다 | "지금 시장에서 무슨 일이 일어나고 있나?" |
| 🔬 Thesis 점검 | 4시간마다 | "내 투자 가설이 아직 유효한가?" |
| 📡 섹터 스냅샷 | 수동 | "반도체/AI/배터리 각각 한 줄 요약" |
| 🚨 이상 신호 | 즉시 | "갑자기 중요한 뉴스가 터졌다!" |

### ④ 배포 — 세 곳에 전달

| 채널 | 용도 |
|---|---|
| 📝 옵시디언 | 보고서를 MD 파일로 저장, 나중에 검색·열람 |
| 💬 디스코드 | 실시간으로 웹훅으로 전송 |
| 📱 텔레그램 | 모바일에서 바로 확인 |

### ⑤ 지식 순환 — 핵심 차별점

```
AI가 만든 보고서 → 다시 AI의 지식으로 축적
                    ↓
             다음에 더 좋은 보고서 생성
```

시간이 갈수록 과거 보고서가 쌓여서 분석이 점점 깊어지는 구조.
