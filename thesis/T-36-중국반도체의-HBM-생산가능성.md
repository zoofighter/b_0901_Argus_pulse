# T-16 중국 반도체의 HBM 생산 가능성

## 핵심 가설
수출통제 우회와 자체 기술 개발을 통해  
**중국이 2027~2028년 내 HBM3E 수준의 양산 능력을 확보**하며,  
이는 글로벌 HBM 공급 구도를 흔들고 가격 하방 압력을 가한다.

## 중국의 기술 경로
1. **TSV(관통전극) 기술**: DRAM 스택 핵심 — 현재 중국 기술 격차 2~3세대
2. **EUV 없는 우회로**: ASML EUV 금지 → 기존 DUV 멀티패터닝으로 회로 축소
3. **CXMT 성장**: 중국 최대 DRAM 업체, 2025년 DDR5 양산 시작
4. **화웨이 생태계**: Ascend 칩 + 자체 HBM 내재화 시도
